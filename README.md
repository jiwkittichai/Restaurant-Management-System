# Restaurant Management System

## ฟังก์ชันหลัก

- ระบบเข้าสู่ระบบและกำหนดสิทธิ์ตามบทบาท
- ระบบจัดการบัญชีพนักงาน
- ระบบรับออเดอร์แบบทานที่ร้านและซื้อกลับบ้าน
- ระบบจัดการโต๊ะและคิวซื้อกลับบ้าน
- ระบบหน้าจอครัวและติดตามสถานะอาหาร
- ระบบจัดการเมนูและหมวดหมู่
- ระบบวัตถุดิบ สูตรอาหาร และการตัดสต็อก
- ระบบบันทึกสถานะและช่องทางการชำระเงิน
- ระบบรายงานยอดขายและเมนูขายดี
- ระบบบันทึกประวัติกิจกรรมของพนักงาน

## เทคโนโลยีที่ใช้

- **Core Framework:** Next.js
- **Frontend & UI:** React, TypeScript, Tailwind CSS
- **Backend & API:** Next.js Route Handlers, Node.js
- **Database & ORM:** MySQL, Prisma ORM
- **Infrastructure & Tools:** Docker, MinIO, phpMyAdmin

## สิ่งที่ต้องติดตั้ง

- Node.js
- Docker Desktop
- Git

## การติดตั้งโปรเจค

### 1. ติดตั้ง Dependencies

```bash
npm install
```

### 2. สร้างไฟล์ `.env` จากตัวอย่าง

```bash
cp .env.example .env
```

### 3. สร้าง Prisma Client

```bash
npx prisma generate
```

### 4. เปิดบริการ Docker

```bash
docker compose up -d
```

### 5. สร้างโครงสร้างฐานข้อมูล

```bash
npx prisma migrate deploy
```

### 6. สร้าง MinIO Bucket

```bash
npm run minio:init
```

คำสั่งนี้จะสร้าง Bucket ชื่อ `products` สำหรับจัดเก็บรูปภาพเมนู และสามารถรันซ้ำได้โดยไม่ลบรูปเดิม

### 7. เปิดเว็บไซต์

```bash
npm run dev
```

เปิดเว็บไซต์ที่:

```text
http://localhost:3000
```

## ข้อมูลจำลองสำหรับทดสอบ
คำสั่ง seed ข้อมูลจำลองลงระบบ
กรอกรายละเอียดลงใน .env เพื่อใช้ในการนำเข้าข้อมูล
-บัญชีแอดมินระบบ
-บัญชีร้าน
และ อื่นๆ

```bash
npm run db:seed
```

## สั่งอาหารผ่าน QR ประจำรอบโต๊ะ
### ทดลองสแกนจากมือถือ

- เปิดเว็บด้วย `npm run dev -- --hostname 0.0.0.0` และให้มือถืออยู่ใน Wi-Fi เดียวกับคอม
- หากเปิดหน้าพนักงานจาก localhost ในโหมดพัฒนา ระบบใช้ LAN IP ใน QR ให้อัตโนมัติ
- หากมีหลายการ์ดเครือข่าย/VPN ให้ระบุ `QR_PUBLIC_BASE_URL=http://<IP ของคอม>:3000` ใน `.env` แล้วเริ่มเซิร์ฟเวอร์ใหม่
- เมื่อโฮสต์จริง ให้ตั้ง `QR_PUBLIC_BASE_URL` เป็นโดเมน HTTPS ที่ลูกค้าเข้าถึงได้ การส่งลิงก์ให้เพื่อนนอก Wi-Fi ร้านต้องใช้ URL ที่เข้าถึงจากอินเทอร์เน็ตได้
- รูปเมนูจาก MinIO ในหน้าลูกค้าโหลดผ่านเว็บร้านโดยอัตโนมัติ รองรับ URL เดิมที่เป็น localhost/127.0.0.1 โดยมือถือไม่ต้องเข้าถึงพอร์ต MinIO โดยตรง

## การกำหนดอีเมลของระบบ สำหรับใช้ฟังก์ชันรีเซ็ตรหัสผ่าน เพื่อใช้ส่งข้อความอีเมลไปยังบัญชีต่างๆ
ต้องตั้งค่า smtp จาก gmail ที่เราจะเซ็ตให้เป็น gmail หลักของระบบที่จะคอยส่งลิ้งไปให้กับอีเมลอื่นที่เรากรอกให้ในการ
